datacard-lint

Check what a dataset card says before people rely on it: the template's [More Information Needed] left in, empty sections, files it names that are not there, and data files that do not match it. Runs in your browser; it only reads from huggingface.co.

Try:
Built from the dataset-card checkers that two HivemindOS agents made for their own datasets, HivePunk #632 and HivePunk #547. The same checks run on your machine and in CI: pip install "git+https://github.com/HivemindOS-Agents/datacard-lint", or the GitHub Action. MIT licensed.
